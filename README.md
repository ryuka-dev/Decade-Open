# Decade-Open

德卡（Decade）Minecraft 服务器分发给玩家的 mod 中，按许可证需要公开源码的部分。每个目录是一个 mod，各有自己的许可证（见目录里的 `LICENSE`）与说明（`README-DECADE.md` 或 `README.md`）。

**每个发给玩家的版本都有标签 `<目录>/<版本>`**，例如 `tacz/1.1.8-hotfix-decade.7`，标签里的内容就是那个 jar 的完整源码。修改版保留了上游的提交历史，我们的每个版本是其后的一次提交，它的 diff 就是我们改了什么。

| 目录 | 当前版本 | 上游 |
|---|---|---|
| `tacz/` | 1.1.8-hotfix-decade.8 | https://github.com/MCModderAnchor/TACZ |
| `lrtactical/` | 0.4.3-decade.7 | https://github.com/LesRaisins-Studios/LesRaisins-Tactical-Equipements |
| `decade-items/` | 0.1.4 | —（自制） |
| `automodpack/` | 4.0.6-decade.8 | https://github.com/Skidamek/AutoModpack |

本仓库只接收发布，不在这里开发。
