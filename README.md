## English

Source code for the mods the Decade Minecraft server (Forge 1.20.1) ships to players, where their license requires the source to be public. Each directory is one mod, with its own license (`LICENSE` in that directory) and notes (`README-DECADE.md` or `README.md`).

**Every version shipped to players has a tag `<directory>/<version>`**, for example `tacz/1.1.8-hotfix-decade.7`. The tag contains the complete source of that jar. Forks keep their upstream history, and each of our versions is one commit on top of it, so that commit's diff is exactly what we changed.

The change tables in each `README-DECADE.md` are in Chinese for now.

This repository only receives releases. Development doesn't happen here.
